适用于 Unity/Mono 引擎游戏 **Captivity v1.0.5b**。

## 使用方法

1. 先启动游戏 `Captivity.exe`，进入主界面（建议先进入关卡再开修改器）。
2. 右键 `Captivity修改器.exe` → **以管理员身份运行**（必需，否则无法读写游戏内存）。
3. 确认“游戏目录”正确，点击 **附加到游戏**。
4. 勾选需要的功能，底部实时显示生效后的数值。
5. 窗口默认**始终置顶**，会稳定显示在游戏画面之上（勾选框可关闭），且不会抢走游戏焦点。

### 语言切换

界面右上角 **语言 / Language / Язык** 下拉框可随时在
**中文 / English / Русский** 之间切换，切换后界面文案立即更新。
选择会记录到 `%APPDATA%\CaptivityTrainer\lang.txt`，下次启动自动沿用；
首次运行（无配置文件）默认为**中文**。

> **请勿同时打开多个修改器。** 程序已做单实例限制；每个修改器实例都会在游戏进程内执行一次线程劫持，多开会显著增加游戏不稳定风险（这正是之前“系统卡死”的原因之一）。

## 功能

| 功能 | 说明 |
|---|---|
| 无敌模式 | 生命全满 + `m_isInvulnerable=true`，免疫伤害 |
| 无限体力 | 体力置为 9999 |
| 力量全满 | 力量拉满，更难被制服 |
| 欲望归零 | 欲望清零 |
| 快感归零 | 快感清零，不会高潮 |
| 心全满 | 生命次数拉满 |
| 无限金钱 | 设置金钱（默认 999999） |
| 无限弹药 | 弹匣/备弹补满 + `m_isAmmoInfinite`（**仅对真实枪械生效**） |
| 一击必杀 | 修改当前武器伤害值（**仅对真实枪械生效**） |

数值类修改（金钱）在游戏内数值发生变动时才会刷新 HUD 显示；无敌/体力/力量等即时生效。

### 关于“无限弹药 / 一击必杀”的安全性

`Player.m_weaponEquipped` 的类型是 `Weapon`，而药物（Aspirin / Morphine / Psycho 等）
也继承自 `Weapon`（经由 `Usable`）。早期版本用数值启发式判断“是否枪械”，会把药物的
无关字段误当成弹药并写入指针字段，导致**游戏闪退**。现已改为读取对象的
**MonoVTable 指针**与 `mono_class_vtable(Gun)` 精确比对：
只有 `Gun` 及其子类 `FlashLight / Grapple / Incinerator / Schockgewehr` 会被写入，
任何 `Usable`（药物）都绝不会被触碰。

## 原理（简要）

游戏为 Unity 2019.3.9f1 + Mono 后端（x64）。修改器通过 Mono 运行时导出函数解析
`CommonReferences.l_instance`（静态单例）→ `PlayerController` → `Player`/`Inventory` →
各字段偏移与 `Gun` 的 vtable，之后完全使用 `ReadProcessMemory/WriteProcessMemory` 读写。

安全软件（如火绒 HIPS）会拦截 `CreateRemoteThread`，因此改为**一次性线程上下文劫持**：
仅在附加时劫持一个非 UI 线程，执行一段自生成的代码完成所有解析（含根域、线程注册、
类/字段/偏移/vtable），随后**完整恢复该线程的上下文**并跳回原地址。要点：

- 栈使用线程自身的栈（换用独立栈会让 Mono 的保守式 GC 扫描越界）。
- 保存并恢复全部易失寄存器，**包括 SSE 的 XMM0–15 与 MXCSR**。
- 跳回原地址使用 `jmp qword ptr [rip+0]`（内嵌目标），**绝不经过任何寄存器**；
  早期版本用 `mov rax,rip; jmp [rax]` 会破坏 RAX，导致主菜单附加时正常、
  但**一进入关卡（加载场景）就闪退**。

因此修改器不驻留、不空转，也不会拖累或破坏游戏。

## 兼容性

- 仅适配 `Captivity v1.0.5b`。若游戏更新（字段名/偏移/类结构变化），解析可能失败。
- 修改器需与游戏同架构（均为 x64）。

## 排查

- **附加失败 / OpenProcess 失败**：未以管理员身份运行。
- **找不到 mono-2.0-bdwgc.dll**：游戏尚未加载 Mono，先启动到主界面再附加。
- **“未找到玩家对象”**：还没进入关卡，进入关卡后即会出现实时数值。
- **无限弹药/一击必杀无效**：当前未装备枪械（需先在关卡内取得手枪等武器），
  或手持的是药物类物品（此时按设计不会修改）。
- **“找不到可挂起的线程”**：修改器会优先借用游戏主线程（消息循环中、不持有运行时锁，
  最安全也最易命中），通常不会出现。若确实出现，请确认游戏未卡死，重开游戏后再附加。
- **附加后无反应**：关闭游戏与修改器后重试。
